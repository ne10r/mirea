# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление», вариант №24.
Реализованы этапы 1–4: интерактивный REPL, конфигурация запуска, загрузка
виртуальной файловой системы (VFS) из XML.

## Требования

- Python 3.10 или новее;
- POSIX shell для `run.sh`.

## Структура проекта

- `src/shell_emulator` — исходный код;
- `examples` — XML-файлы VFS для демонстрации;
- `tests` — автоматические тесты;
- `scripts` — стартовые файлы и сценарии запуска этапов;
- `run.sh` и `Makefile` — запуск приложения и тестов.

## Запуск

Интерактивный режим:

```sh
./run.sh
```

С параметрами этапа 2:

```sh
./run.sh --vfs-path ./examples/vfs.xml \
  --startup-script ./scripts/demo_startup.txt
```

VFS загружается в память из XML. Исходный файл не распаковывается и не
изменяется. Поддерживаются текстовые файлы UTF-8 и двоичные файлы в base64.

Пример XML:

```xml
<vfs name="demo">
  <directory name="docs">
    <file name="readme.txt">Текстовый файл.</file>
    <file name="data.bin" encoding="base64">AAECAwQF</file>
  </directory>
</vfs>
```

Также доступны демонстрационные сценарии:

```sh
./scripts/run_stage2_demo.sh
./scripts/run_stage2_errors.sh
```

Сценарии этапа 3:

```sh
./scripts/run_stage3_minimal.sh
./scripts/run_stage3_files.sh
./scripts/run_stage3_nested.sh
./scripts/run_stage3_errors.sh
./scripts/run_stage4.sh
```

Они проверяют минимальную VFS, несколько файлов с base64-данными, вложенность
каталогов не менее трёх уровней и ошибки загрузки отсутствующего и некорректного
XML-файлов.

## Поддерживаемые команды

- `ls [путь]` — выводит содержимое каталога подключённой VFS;
- `cd [путь]` — меняет текущий каталог в памяти подключённой VFS;
- `vfs-info` — выводит имя VFS, текущий каталог и статистику;
- `clear` — очищает экран управляющей последовательностью терминала;
- `pwd` — выводит текущий путь в VFS;
- `exit` — завершает сеанс.

Если VFS не подключена, `ls` и `cd` сохраняют режим заглушек этапа 1.
Аргументы в кавычках поддерживаются, например `cd "my documents"`.
В стартовом скрипте ошибочные строки выводятся с номером строки и пропускаются.

## Тестирование

```sh
make test
```

Тесты покрывают разбор кавычек, REPL, команды-заглушки, обработку ошибок,
параметры CLI, XML-загрузку VFS, навигацию по дереву и выполнение стартовых
скриптов.
